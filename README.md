# -Project-PiSheet
Project PiSheet は、(cmでない)通常のRaspberry Pi 5をベースとした超薄型・一体型コンピュータを開発するプロジェクトです。

一般的なRaspberry Piでは、基板上にUSBポートやLANポート、HDMIコネクタなどの大型部品が実装されているため、本体の厚さはこれらのコネクタによって決まります。Project PiSheetでは、不要なコネクタや部品を取り除き、フレキシブルケーブルや薄型部品へ置き換えることで、携帯性とデザイン性を両立した新しいRaspberry Piの形を目指します。

* 圧倒的な薄型化
    * コネクタ類を排除・置換することで、本体厚みを大幅に削減。
* 携帯性の向上
    * ポケットや小型ケースへ収納しやすい設計。
* 高い一体化
    * ディスプレイ、バッテリー、SSDなどを内部に組み込み、配線を最小限に抑えられる。
* ケース設計の自由度
    * コネクタの突出が少ないため、オリジナル筐体を薄く、美しく設計できる。
* 省スペース化
    * 狭い場所への組み込みやウェアラブル機器、ロボットへの搭載に適している。
* カスタマイズ前提の設計
    * 必要なインターフェースのみを引き出すことで、用途に応じた最適な構成を実現できる。
* Raspberry Pi 5の性能を維持
    * 超薄型化を図りながらも、Raspberry Pi 5の演算性能やソフトウェア資産をそのまま利用できる。
* 新しいフォームファクタ
    * 従来のシングルボードコンピュータではなく、「シート状コンピュータ」という新しいカテゴリを目指す。
